# Budget — รายรับรายจ่าย + AI

รุ่นเขียนใหม่ของ `porbboyza-afk/budget-app` จดรายรับ–รายจ่ายและใช้ AI ช่วยเตรียมรายการ

## เปิดใช้งาน

ใช้ Node.js 20 ขึ้นไป รัน `npm run dev` แล้วเปิด http://127.0.0.1:8771 อย่าใช้ Python static server สำหรับรุ่น AI เพราะไม่มี API ฝั่งเซิร์ฟเวอร์

คัดลอก `.env.example` เป็น `.env.local` และตั้ง `DEEPSEEK_API_KEY` หรือ `DEEPSEEK_ENV_FILE` ชี้ไฟล์ env เดิม เซิร์ฟเวอร์อ่านเฉพาะ DeepSeek key จากไฟล์นั้น ไม่ใส่ key ใน browser หรือ Git

ไม่มี dependencies สำหรับ build; ต้องเปิดผ่าน HTTP เพื่อโหลด JavaScript modules

## ลองได้ในดราฟนี้

- การเปิดใหม่เริ่มรายการว่าง ตามที่ผู้ใช้เลือกเริ่มใหม่ ข้อมูลที่จดในดราฟนี้แล้วคงอยู่
- เพิ่ม แก้ไข ลบ และย้อนกลับการลบล่าสุดระหว่างเปิดหน้า
- เลือกเดือน/ปี ค้นหา กรองประเภท และสรุปรายเดือน
- เก็บข้อมูลแยกใน browser storage; สำรอง JSON และกู้คืนแทนชุดปัจจุบันหลังยืนยัน
- ส่งออก CSV ของเดือนที่เลือก
- เงินคงเหลือคือยอดทั้งหมดถึงสิ้นเดือนที่เลือก รายรับ/รายจ่ายคือเฉพาะเดือนนั้น

## ขอบเขต

เมื่อเข้าสู่ระบบบัญชีเจ้าของ รายการจะซิงค์ D1 และมีสำรองใน browser แยกตาม UID ก่อน login ใช้ชุดข้อมูลในเครื่องแยกต่างหาก ไม่มีการย้ายข้อมูลแอปเก่าหรือ PWA ต้องสำรองก่อนล้าง browser data; undo หายหลัง reload ไม่มีการแก้ฐานข้อมูลแอปเดิม

## AI

- ข้อความ/ใบเสร็จ/สลิป → รายการที่แก้ไขได้ → ผู้ใช้ยืนยันก่อนบันทึก ต้องออกจากข้อมูลตัวอย่างก่อนใช้
- ส่งภาพเมื่อกดอ่านเท่านั้น ย่อด้านยาวไม่เกิน 2400px และแปลงใหม่เพื่อตัด metadata; ไม่เก็บภาพที่เซิร์ฟเวอร์ แต่ภาพถูกส่งไป DeepSeek
- สลิปที่ไม่มีวัตถุประสงค์ต้องให้ผู้ใช้เติม ห้ามถือว่ารู้ว่าซื้ออะไรจากชื่อผู้รับ
- คำถามใช้รายการเดือนที่เลือกไม่เกิน 500 รายการ โดยไม่รวม ID; ยอดคำนวณด้วยโค้ดฝั่งเซิร์ฟเวอร์
- API key อยู่เซิร์ฟเวอร์เท่านั้น; คำตอบ AI แสดงเป็นข้อความและตรวจ schema

## Cloudflare Pages

`npm run build` สร้างเฉพาะ public assets ใน `dist` และปฏิเสธไฟล์แปลกปลอมที่ตกค้าง ตั้ง Build command เป็น `npm run build`, Output directory เป็น `dist` และเปิด Pages Functions

ตั้ง server secrets/config: `DEEPSEEK_API_KEY`, `FIREBASE_WEB_API_KEY`, `FIREBASE_PROJECT_ID`, `FIREBASE_AUTH_DOMAIN`, `BUDGET_ALLOWED_EMAILS` โดยใช้ Firebase โครงการ Budget เดิม

สร้าง D1 database รัน `schema.sql` และผูกชื่อ `BUDGET_AI_DB` endpoint จะปฏิเสธหากไม่มีบัญชีเจ้าของหรือ quota binding จำกัด 5 ครั้ง/นาที, 60 ครั้ง/บัญชี/วัน และ 100 ครั้งรวม/วัน (UTC) รวมคำขอที่ provider ล้มเหลว ไม่ใช่การรับประกันยอดเงินค่า API เป๊ะ

Google sign-in ต้องเปิด provider และอนุญาต domain ใน Firebase ก่อนใช้งานจริง อ่าน `RELEASE_HANDOFF.md` ก่อน merge/deploy ผู้ใช้เลือกเริ่มใหม่โดยไม่ย้ายข้อมูลเก่า ห้ามคัดลอก `.env*`, `.dev.vars*` หรือข้อมูลจริงเข้า Git

การตรวจ: independent source review และ synthetic CAS checks ผ่าน; Brave Google login, เพิ่ม/แก้/ลบ/ย้อนกลับและซิงค์ขึ้น D1, รีเฟรชคงข้อมูล, DeepSeek ข้อความและถามยอดผ่านจริง ภาพใบเสร็จ/สลิปไทยสังเคราะห์ผ่าน แต่ยังไม่ได้ประเมินกับภาพจริงหลากหลายรูปแบบ

เว็บใช้งาน: https://budget-app-porbboyza.pages.dev ลิงก์ GitHub Pages เดิมส่งต่อมาที่เว็บนี้

`model.js` ตรวจข้อมูลและคำนวณหน่วยสตางค์; `app.js` จัดการหน้าจอและstorage; `styles.css` จัดlayoutมือถือ/คอม; `index.html` เป็นหน้าจอหลัก
